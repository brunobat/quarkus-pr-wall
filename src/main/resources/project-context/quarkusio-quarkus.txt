Project context. The repository is Quarkus (quarkusio/quarkus): a Java framework for cloud-native applications, built with Maven. Layout conventions:
- extensions/<name>/runtime/src/main: code shipped in users' applications and run there.
- extensions/<name>/deployment/src/main: build-time code (@BuildStep) that runs while users' applications are built; it is shipped and shapes the built application.
- core/ and independent-projects/: framework core, shipped.
- bom/application/pom.xml and other pom.xml dependency versions: the libraries shipped to users; a version upgrade can change runtime behaviour.
- Tests are classes and resources under src/test/ (JUnit 5, @QuarkusTest, QuarkusUnitTest in extension deployment modules, @QuarkusIntegrationTest).
- integration-tests/<name>/: modules that exist only for testing and are never shipped. Only their src/test/ holds tests; their src/main/ is the application the tests exercise, and their pom.xml only builds that module.
- test-framework/: infrastructure used by tests; it is neither a test nor shipped runtime code.
- docs/src/main/asciidoc: documentation.
A PR adds or modifies tests only if it changes files under a src/test/ directory.
