# Voluntary AI-assistance declarations (authorship-provenance design §4.1).
#
# A match means the PR SAYS it used AI tooling. It is an attestation, never an accusation, and it can
# only ever route the PR to a deeper look — invariant I-7 forbids any rule that penalises a declaration,
# and RulesetLint enforces that mechanically. Absence of a match means NOTHING: the overwhelming
# majority of AI-assisted PRs carry no marker at all, so "no signal" is not evidence of hand-written
# code and is never reported as such.
#
# Case-insensitive substring per line; blank lines and #-comments ignored. Matched against commit
# message bodies AND the PR body, because both carry declarations in practice: on quarkusio/quarkus as
# of 2026-10-21, "Co-Authored-By: Claude" appears in 126 commits while "Generated with Claude Code"
# appears in 17 PR bodies and 0 commits. Checking only one of the two misses most of the population.
#
# Deliberately NOT here: anything that tries to infer tooling from prose style, emoji, or structure.
# That is stylometry; it does not work, and §9 of the research says so in as many words.
